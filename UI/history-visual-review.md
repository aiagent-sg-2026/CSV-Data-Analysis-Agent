# Analysis History modal — visual review

1. **Improved — screenshot evidence:** The mobile modal now uses the available width for the search field and sorting controls, while keeping the history entries readable. The desktop view presents the same controls in a compact row and leaves generous space for report names and actions.

2. **Remaining visible UX issue — screenshot evidence:** On mobile, a report’s previous-version entry is visually separated from its parent by a large vertical gap and divider; the repeated metadata and resume action make the relationship less immediately clear. The open overflow menu also covers portions of the report list, as expected for an overlay but with little unobstructed context in this narrow view.

3. **Cannot verify from screenshots:** These captures show the modal at rest, with storage expanded in one image and an overflow menu open in another. They do not prove search, sorting, scrolling, menu actions, version expansion, keyboard/focus handling, or responsive behavior at other viewport sizes.
